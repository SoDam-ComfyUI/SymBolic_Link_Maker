# 폴더 링크 명령어 생성기

`Symbolic_Link_Maker_Upgraded.html`은 Windows와 Linux에서 폴더 링크를 만들기 위한 **명령어만 생성하는 오프라인 도구**입니다. 이 페이지는 어떤 명령도 직접 실행하거나 파일을 변경하지 않습니다.

## 사용 방법

1. `Symbolic_Link_Maker_Upgraded.html`을 브라우저로 엽니다.
2. 운영체제와 연결 방식을 선택합니다.
3. 원본 폴더 경로를 입력합니다.
4. 링크를 만들 상위 위치와 새 링크 폴더 이름을 입력합니다.
   - 원본 경로의 마지막 폴더 이름이 자동으로 제안됩니다.
   - 화면의 `생성될 링크 경로` 미리보기를 확인합니다.
5. `명령어 생성`을 누르고, 결과를 검토한 뒤 `복사`를 누릅니다.
6. 해당 운영체제의 터미널에 붙여넣어 실행합니다.

## 연결 방식

| 운영체제 | 방식 | 생성 명령 | 설명 |
| --- | --- | --- | --- |
| Windows | 디렉터리 심볼릭 링크 | `mklink /D` | 원본 폴더를 가리키는 링크입니다. 개발자 모드 또는 관리자 권한이 필요할 수 있습니다. |
| Windows | 디렉터리 정션 (Junction) | `mklink /J` | Windows 전용 디렉터리 연결 방식입니다. 하드 링크가 아니며, 일반적으로 관리자 권한이 필요하지 않습니다. |
| Linux | 디렉터리 심볼릭 링크 | `ln -s --` | 표준 Linux 심볼릭 링크입니다. |

> Linux의 일반적인 디렉터리 하드 링크는 지원하지 않습니다. 안전하지 않은 `ln -P` 안내도 제공하지 않습니다.

## 실행 전 확인

- 원본 폴더는 실제로 존재해야 합니다.
- 새 링크 경로는 존재하면 안 됩니다. 같은 이름의 폴더나 링크가 있으면 먼저 확인하고 다른 이름을 사용하세요.
- 원본 폴더와 새 링크 경로는 서로 달라야 합니다.
- 생성된 명령은 먼저 읽어 본 뒤 실행하세요.
- Windows 심볼릭 링크는 환경에 따라 권한 오류가 날 수 있습니다. 이 경우 개발자 모드를 켜거나 관리자 권한 CMD에서 실행하세요.
- 정션은 Windows 전용입니다. 이동식 저장장치나 네트워크 경로에서는 사용 전 동작을 확인하세요.

## 입력 검증

도구는 다음과 같은 실수를 사전에 차단합니다.

- 빈 경로, 상대 경로, 줄바꿈 또는 제어 문자
- Windows에서 사용할 수 없는 링크 이름 문자 및 예약 장치 이름
- Windows 링크 이름의 끝 점 또는 끝 공백
- 원본 폴더와 생성될 링크 경로가 같은 경우

입력을 변경하면 이전에 생성된 명령어는 자동으로 숨겨집니다. 이전 경로의 명령을 실수로 복사하지 않도록 하기 위한 동작입니다.
